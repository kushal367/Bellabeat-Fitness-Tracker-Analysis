# Bellabeat Fitness Tracker Analysis

## Project Overview

This project analyzes Bellabeat fitness tracker data using SQL to understand customers' daily activity, sleep patterns, and weight records. The analysis uses three datasets: Daily Activity, Sleep, and Weight Log, to identify useful patterns in customer behavior and answer business-related questions.

## Analysis

The project analyzes customers' most and least active days based on steps, sleep patterns, missing sleep records, customers with complete activity, sleep and weight records, daily sleep duration, highest and lowest recorded weights, the day customers sleep the most, time spent in bed without sleeping, the most frequently occurring day of the week, and the average distance covered based on 6,000 steps.

## Tools Used

PostgreSQL, SQL, and CSV datasets.
