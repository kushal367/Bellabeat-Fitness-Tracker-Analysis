# Bellabeat-Fitness-Tracker-Analysis
This project analyzes Bellabeat fitness tracker data using SQL to understand customers' daily activity, sleep patterns, and weight records.  The analysis uses three datasets containing information about daily activity, sleep, and weight logs. SQL queries are used to answer business-related questions and identify useful patterns in customer behavior
The project uses three datasets: Daily Activity, Sleep, and Weight Log. The analysis explores customers' most and least active days based on steps, effective sleep patterns, customers with missing sleep records, and customers with complete activity, sleep, and weight records. It also analyzes daily sleep duration, highest and lowest recorded weights, the day customers sleep the most, time spent in bed without sleeping, the most frequently occurring day of the week, and the average distance covered based on 6,000 steps. The project was developed using PostgreSQL and SQL, with CSV datasets as the source data.
